# 资料解析与工具路由

## 文件盘点

对每个文件记录路径、扩展名、大小、推定类型、角色、可读状态和备注。角色使用：`official_info`、`official_asset`、`reference`、`inspiration`、`unknown`。不要仅凭文件名判断内容。

## 格式处理

| 输入 | 处理 | 需要保留 |
|---|---|---|
| PDF | 提取文本、表格、页码和图片；扫描件执行 OCR | 页码、段落位置、OCR 置信度 |
| DOCX | 提取标题、正文、表格、批注和内嵌媒体 | 文档结构、表格位置、媒体关系 |
| PNG/JPEG/WebP/TIFF | OCR + 图片理解 + 技术信息 | 主体、文字、留白、裁切安全、分辨率、风险 |
| SVG | 识别画布、矢量元素和嵌入文字 | 是否为 Logo、字体依赖、可编辑性 |
| TXT/MD/CSV/JSON/YAML | 结构化读取 | 编码、字段来源、冲突 |
| ZIP | 先列清单，再解压到独立工作区 | 原 ZIP、层级、重复文件、异常路径 |

解析失败时记录文件、失败阶段、错误和替代方法。不要丢弃原始输入或声称已读取不可读内容。

## 图片与素材索引

每项素材记录：`asset_id`、来源、主体、文化关系、角色、分辨率、主体位置、裁切安全、文字安全区、水印或版权风险、是否含文字、正式使用状态。角色使用 `core / support / logo / qr / reference / unusable`。

## 多主体素材的选择范围

编号索引之外，还须区分“适用主体素材总数”与“已确认使用数量”。多图但未指定使用范围时，先展示总览并按[素材使用与拼贴](asset-usage-and-collage.md)询问；不将AI单图择优写成用户已选择。明确编号/数量可复用，Logo和参考图不混入主体计数。

## 工具路由

| 任务 | 工具能力 | 输出 | 人工点 |
|---|---|---|---|
| 文件盘点 | 文件系统脚本 | manifest | 确认特殊文件角色 |
| PDF/Word 解析 | 文档解析/OCR | 带来源文本 | 复核关键字段 |
| 图片识别 | 图像理解/OCR | 素材索引 | 复核文化对象和授权 |
| 事实研究 | 可引用检索 | 证据记录 | 确认冲突和权威来源 |
| 主视觉 | 图像生成/编辑 | 无正式文字图像 | 选择方向和文化适切性 |
| 正式排版 | 图形/版面工具 | 可控文字版本 | 复核层级和可读性 |
| QA | 文本比对、视觉检查、脚本 | 质量报告 | 审美和传播效果 |
| 导出 | 设计或图像工具 | 最终文件 | 批准正式发布 |

工具输出不能自动升级为事实。OCR、翻译、图片识别和生成结果均需保留置信度或审核状态。
