# 混合主题与分层视觉适配

用于文化题材与呈现机制不同，或用户反馈涉及背景、装饰、拼贴及相对排版关系的任务。仅加载实际相关类别；一个主模板组织信息，支撑模板提供可兼容角色，不能机械叠加两套完整版式。

## 主机制与文化角色

- 按观众行为及真实展示形式确认主类别；传统×数字时可由数字艺术安排信息网格与阅读路径，传统文化提供真实文化对象、字体角色和纸/竹/印刷材质依据。
- 记录每个采用项的来源、用途和主语言模板约束。更改锁定字体、错位/居中、底板或导引机制时，使用模板允许项或本题明确用户覆盖；已有覆盖直接复用。没有覆盖时不把“融合”当解除全部约束。
- 文化字体用于哪个标题/工艺层由本题方向决定；正式展讯保留可读性。中英分别选择真实可用字体，不将本案字体变成所有混合活动必选。

## 独立图层及保留范围

建议按实际需要区分：全画布纸纹/印刷底、背景文化主体、前景主体集合、装饰纹理、工艺线索/轨道、正式文案、真实Logo/二维码。每层记录源、用途、bbox、裁切、alpha倍率与用户依据；项目源在Skill之外保存。

- “去素材/拼贴背景”处理素材自带底或拼贴底，保留已锁定纸底；“去整个底图”才改变全画布底。语境可确定时直接执行，无法确定且影响大时只问这一处范围。
- 背景主体按用户选择裁切和显示比例，不因放大产生未经说明的身份缺失；以实际alpha主体bbox定义“上半部/上三分之一”，记录坐标。前景保留源图形制和编号映射。
- 透明素材优先作为可复用资产。只改单层大小、位置、alpha或文本关系时用现有原生布局/合成工具重排；仅在确需新位图内容或工具编辑时调用图像生成，保留参考与输出并披露保真限制。
- 看alpha实际内容而非透明画布尺寸；非常淡的外围像素会影响缩放边界。裁边阈值由本题素材确定并记录，只用于边界时不要顺带阈值化主体内部。对文化主体保持比例；抽象装饰的非等比适配需符合当前指令并记录，不推广到器物/人物变形。

## 关系式排版

使用可配置的约束，避免将本案绝对坐标固化进Skill：

| 用户意图 | 求值/检查方法 |
|---|---|
| 标题与文化说明居中 | 对指定参照区计算实际文字bbox中心，计入负bearing；记录字体和容差 |
| 素材左右均分/对称 | 依据确认集合分配槽位，镜像槽位坐标而非镜像不同作品；核对编号与实际可见区域 |
| 工艺线索左右分布、词与轨道对中 | 分开记录左右集合和每个词/轨道的中心，工艺字采用标题字体仅在明确要求/允许时执行 |
| 同级展讯相同字号/字重 | 共享相同层级样式；只使用真实字重文件或支持的变量轴 |
| 右侧信息与橙线/矩形右对齐 | 使用该图形实际右边界作锚点，而非手猜文字起点 |
| 英文信息减少换行、与左右信息齐顶齐底 | 先在允许宽度内增加单行容量，按整段bbox检查上下缘与安全区；不删信息 |
| 拆分标题与副标题，不要冒号 | 保留全部名称词组，按用户依据隐藏排版分隔符并留文案适配记录；不改专名本体 |
| 去白色/橙色信息块或虚线 | 单独移除指名图层/端点，保留未涉及的纸底、轨道和文字；复查对比 |
| 顶部装饰与画布同宽、底缘齐Logo | 从画布宽和Logo实际下沿求装饰目标bbox，置于文字/标识下层；复查顶栏 |

“对称/居中”是本题可选布局，不是文化海报必选。字段C02/C03等ID来自当前母本映射，不硬编码为全部任务的统一字段。

## 强度匹配与歧义

内部统一记录`opacity`为0..1的不透明度倍率，并说明是对原alpha相乘。用户明确说“与背景一致”时从已确认参照层读取倍率；不再次询问已知值。仅有“降低透明度”等可能被理解为更淡/更实、且无参照时，再简短确认方向。没有参照或指定值时，不把20%当默认值。

尺寸、内容和alpha一致不代表不同素材视觉浓淡绝对一致，需视觉复查并让用户评判。降低alpha只能淡化内部底色色区，不能宣称完成抠图。装饰不新增文化主体数量。

## 局部复查与停止

先保存完整中英版本，再做本轮检查。核对事实、所选集合、未改图层参数、目标关系、边界和文字对比。原生同画布修改可用像素差bbox验证变化范围，记录是否包含移除旧层的区域；采样方法与阈值不能充当公众实验。

新增问题和未解决提示偏差保留，普通排版可继续在已授权范围修复。按既有严重问题Gate处理硬冲突；用户已给具体反馈不再重复确认同一内容。最终技术通过与用户审美接受分开记录，发布另按授权执行。
