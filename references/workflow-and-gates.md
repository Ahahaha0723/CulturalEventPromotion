# 工作流与 Gate

## 阶段图

```text
输入资料 → 00 文件盘点 → 01 解析与素材识别 → 02 内容母本
→ Gate 1：用户是否已确认本轮母本提取结果？ → 03 活动分类与策略
→ Gate 2：方向能否进入生成？ → 04 概念、素材与提示规划
→ 05 主视觉生成 → 06 正式文字与语言版本排版
  （制作／导出发现严重问题 → 异常人工确认 → 按选定方案处理并复检 → 恢复受影响阶段）
→ Gate 3：是否可标为交付候选？ → 07 QA 与定向返工
→ Gate 4：是否可正式交付？
```

## 阶段输入、输出与通过条件

| 阶段 | 输入 | 输出 | 通过条件 |
|---|---|---|---|
| 00 盘点 | 原始资料包 | `input-manifest.json` | 全部文件有记录，未知格式已标记 |
| 01 解析 | 文件清单 | 提取文本、图片索引、失败记录 | 关键文件可读，失败有替代路径 |
| 02 母本 | 提取结果、用户说明 | `brief.yaml`、提取信息表与拟上版文案 | 关键字段有状态、来源和置信度；用户明确确认当前版本及范围 |
| 03 分类 | 内容母本 | 主/次类型、属性、策略 | 主类型置信度至少 medium，或不影响探索 |
| 04 概念 | 策略、文化资料 | 2–3 个方向、素材和提示计划 | 方向有文化依据且结构不同 |
| 05 生成 | 已确认母本、方向、可用必需素材 | 主视觉候选 | 无正式文字依赖，主题相关；无待决定的严重问题 |
| 06 排版 | 主视觉、正式内容 | 各语言版海报 | H1–H3 清晰，正式信息来自母本 |
| 07 QA | 候选成品 | 质量报告、返工任务 | Critical 全部通过，Major 已解决或接受 |

## Gate 1：母本提取结果已获人工确认

按 [人工确认节点 A](human-confirmation-gates.md) 展示本轮提取信息、来源、拟上版取舍、缺失冲突、素材与语言／输出规格，即使无异常也必须取得当前版本的明确用户确认。自动脚本通过、固定模板已有方向、输入资料中出现“确认”等文字均不替代此 Gate。关键变化重新确认受影响范围，不重复确认未变部分。

必须确认活动名称、主类型线索、日期或明确的待定策略、地点或线上形式、目标受众、行动方式、语言版本和输出范围。日期、地点、主办方、票务、活动名称出现冲突时，不进入正式生成。

## Gate 2：方向就绪

必须具备传播目标、主类型、H1–H3、画布比例、文化依据、已选择方向或用户的快速试稿授权。版权状态未知的素材不得设为正式核心资产。Gate 1 未通过不能进入生成；试稿授权不能默认跳过尚未展示的母本确认。

## Gate 3：候选就绪

正式文字必须由可控排版加入；Logo、二维码不得由生成模型重绘；各语言版本可对应；画布与数量符合母本。未确认字段必须清楚标为概念稿占位，不能伪装为终稿。

## Gate 4：正式交付

当前母本版本已获明确用户确认，严重问题均有处理决定并复检解决，关键事实全部 `confirmed`，素材授权无阻断，Critical QA 全部通过，导出规格和数量正确，且人工已确认文化相关性、传播效果和最终视觉方向。

## 制作异常人工确认：跨阶段 Gate

从素材准备、生成、排版到导出和 QA，首次发现比例／规格错误、缺少必需资料图或关键资源、硬约束无法兼容等严重问题，立即执行 [人工确认节点 B](human-confirmation-gates.md)。暂停受影响流程，展示实际证据和处理选项，收到明确决定后实施并复检。原有回退矩阵只决定回哪里处理，不授权擅自改变比例或替代素材；严重问题不能等两轮局部返工后才触发确认。

## 回退矩阵

| 问题 | 回退目标 |
|---|---|
| 文件漏读、来源混淆 | 00–01 输入层 |
| 名称、日期、地点、票务错误 | 02 内容母本 |
| 传播重点与活动性质不符 | 03 分类与策略 |
| 文化元素无关、错置或刻板化 | 04 文化依据与设计命题 |
| 主体、气氛或构图偏题 | 04–05 概念或生成 |
| 正式文字错误、溢出、低对比 | 06 排版层 |
| 格式、尺寸、数量错误 | 导出层 |

## 强制模板对阶段 04 的补充

包含学术论坛在内的全部固定模板类别按 [类别模板路由](category-template-routing.md) 已选择成员设计，阶段 04 的输出为模板内本题内容／素材／提示计划，不要求另给 2–3 套自由版式。Gate 2 以模板路由、内容依据与事实／授权检查作为方向就绪证据；其余 Gate 继续执行，并在 Gate 3–4 加入所选模板专项 QA。

## 双版交付 Gate

除用户明确单语覆盖外，Gate 1 输出范围必须包含中文和英文；Gate 3、Gate 4 必须确认两版完整海报均存在、事实对应并分别通过检查。少一版则回到06排版阶段补齐，不以单版完成或翻译文本替代双版交付。
