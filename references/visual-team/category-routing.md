# 活动类别与视觉策略路由

沿用八个大类，动漫及游戏展归潮流类，电影归演出类，党团活动归展览类红色主题。每行是可选路线，不指定唯一风格。标为设计推导的部分可直接用于设计，但不能说已经经过该小类的第二轮机制校准。

策略索引：S01主次与留白；S02主题对象；S03材料隐喻；S04角色场景；S05信息模块；S06色彩情绪；S07字体表达；S08同题择优。
## 展览类

|小类|优先策略|设计方向|本轮证据范围|
|---|---|---|---|
|文物／考古展、传统文化／非遗工艺展|S02 → S01 → S03|明确文物、作品或工艺的主题细节；实物优先可辨，题名与展期独立。|本轮有文物／考古参考；非遗工艺方向为设计推导；来源：展览-002、展览-186|
|绘画／书法展、摄影展|S02 → S07 → S01|以实际作品或题名字形形成主题，功能字退出表现性字体；不要让作品名替代活动形式。|每小类只有1人机制记录，摄影参考只宜局部借用；来源：展览-070、展览-096|
|数字艺术展、设计／建筑展、综合当代艺术展|S02 → S07 → S01|从作品系统或主题形态提炼视觉；大字、拼贴、数字感均是可选路线。|建筑／当代艺术有单人记录，数字艺术为设计推导；来源：展览-109、展览-125|
|红色主题展览／党团活动|S02 → S06 → S05|先明确历史主题、纪念对象或活动行动，再处理庄重／青春情绪；保留事实核验。|1人部分认可，缺具体说明，颜色只能条件调用；来源：展览-167|
|博物馆综合活动|S05 → S02 → S01|多场次先形成信息网格，再以器物或材料作主题识别；拥挤时减少附加装饰。|单人记录，含拥挤风险；来源：展览-185|
## 演出类

|小类|优先策略|设计方向|本轮证据范围|
|---|---|---|---|
|Livehouse／独立音乐演出|S08 → S01 → S06|按具体音乐气质处理动势与留白；演出类型、阵容和入场信息另设层级。|单人案例＋5人结构稿选择；没有真实观众效果证据；来源：演出-039、T02|
|音乐节／大型潮流演出|S05 → S08 → S06|阵容与场次若决定购票，建立分组与阅读顺序；主题视觉可丰富，但不要让密集信息等权。|设计推导；第二轮没有此小类机制记录；来源：无该小类机制记录|
|戏曲演出、交响乐／古典音乐会|S02 → S01 → S07|从具体剧目、音乐主题或舞台语言出发；传统符号必须与实际内容相符。|设计推导；第二轮没有戏曲、交响乐机制记录；来源：无该小类机制记录|
|民族／国风音乐会|S01 → S07 → S02|可用线条、书写或传统内容表达气质，但不机械堆叠国风元素；信息区保持稳定。|1人机制记录；来源：演出-065|
|话剧／舞剧／叙事演出|S03 → S02 → S01|材料隐喻先解释与剧情的关系；无法说明时回到人物、动作或关键物件。|话剧5人意见有分歧；舞剧为设计推导；来源：演出-097|
|电影上映、电影放映／影像周|S02 → S01 → S05|叙事视觉／片名与放映信息分层；多个单元需要信息组织。|两小类各1人，含难读与局部借用条件；来源：演出-132、演出-134|

## 体育类

|小类|优先策略|设计方向|本轮证据范围|
|---|---|---|---|
|足球／篮球等对抗赛事|S02 → S01 → S07|赛事识别、对阵与开赛信息优先；身体动作或关键物件建立运动主题。|足球1人；体育-052是形象参考，不证明赛事信息完整；来源：体育-004、体育-052|

## 学术类

|小类|优先策略|设计方向|本轮证据范围|
|---|---|---|---|
|学术会议／论坛、学术讲座|S01 → S05 → S07|建立题目、讲者／组织者、时间地点的信息层级；字体气质不能替代议题与事实。|讲座2人认可主次；论坛1人部分认可字体，仅局部借用；来源：学术-013、学术-015|
|艺术疗愈／体验工作坊|S01 → S02 → S05|留白与轻质感支持安静体验，但题名、形式、时间地点和报名方式必须可读。|5人基本认可，4人选主次，2人指出难读；来源：学术-113|
|书籍／印刷／手作工作坊|S02 → S05 → S01|工具与材料说明会做什么，副标题写清学习制作，区别于书展或售卖。|1人机制记录；来源：学术-084|
|设计／建筑工作坊|S05 → S01 → S07|主题字形或结构图形支持表达，参与对象与工作坊形式不可被双语或大字挤掉。|2人选择不同机制，分别指出可读或定位风险；来源：学术-076|

## 跨类别调用例

同是针线、书本或手作工具：工作坊强调学习制作，市集强调购买交流，展览强调观看内容。可共用S02的对象表达，但副标题、功能区与行动指令分别重建。

同是人物与场景：动漫体验可用S04，社区共创需要“我能加入什么”的说明，大众体育需要实际报名条件与行动线索；角色数量与画面热闹程度不直接决定类别适配。
