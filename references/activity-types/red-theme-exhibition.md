# 红色文化／党史主题展览

## 类别与边界

- 保持 `primary_type: exhibition`，次类型／`module_id`: `red-theme-exhibition`；成员所称类型标签映射到次类型，不新增总分类枚举。
- 适用于党史、革命文物、历史档案、主题教育展；红色配色本身不足以触发。红色主题为主时优先于一般传统文化展览策略。
- 展名和主叙事 > 展期、开放时间、地点 > 展陈内容／策展单元 > 预约讲解与参与 > 主办承办。不虚构历史人物、徽章、标语、文物或历史叙述。

## 必须读取的成员模块

| 语言 | 完整入口 |
|---|---|
| 中文 `zh-CN` | [红色主题中文模块](../../assets/category-templates/red-theme-exhibition/zh-CN/SKILL.md) |
| 英文 `en` | [红色主题英文模块](../../assets/category-templates/red-theme-exhibition/en/SKILL.md) |

按入口读取叙事、字体和专项 QA。真实策展内容确定一种主叙事、至多一种辅助叙事；建立历史 Evidence Ledger，核对人物、年份、影像、档案、文物来源与使用条件。时间线仅在内容需要并已确认时使用，非时间线方案须检查隐含年份演进。保留成员防模板化规则，不把红金、飘带、固定年份、历史照片拼贴或时间轴设为默认答案。

统一策展单元的字号与对齐，保持远距视觉锚点；遮住标题后仍能识别展览身份。政治、历史、机构专名及英语译名须准确；生成概念、伪造档案文字或合成照片不能冒充原史料。

### 字体状态覆盖

原成员包未附字体二进制，先前已补齐思源宋体 Regular/Bold、思源黑体 Regular/Bold、霞鹜文楷、Nunito Regular/Bold；用户现已补交马善政与志莽行书，两份均与原成员SHA256完全一致，连同随包OFL接入共享目录，九份字体全部可用。各语言 `font-manifest.json` 记录实际路径、内部名称、原版hash与许可证。按叙事分配宋、黑、文楷与短标题书法角色。

**志莽行书与马善政现已可用**，取代先前“不可用”的临时状态。共享路径分别为总包 `assets/fonts/member-modules/zhi-mang-xing/ZhiMangXing-Regular.ttf` 和 `assets/fonts/member-modules/ma-shan-zheng/MaShanZheng-Regular.ttf`，各自随包 `OFL.txt` 已保留。提示计划与排版必须按两版 `references/red-theme-typography.md` 调用 `scripts/resolve_font.py`，保存实际绝对字体文件、hash、许可与锁定标题，再真正加载；不能只在生图提示里写名字。仅用于审核后的简短H1／重点词，不默认所有红色主题用书法，不用于历史事实小字。既有传统文化展览／传统表演的独立马善政版本保持原样。

运行成员 `scripts/check_fonts.py` 核对九份可用字体；按新活动实际文字运行字体绑定器检查完整字形。`render_font_sample.py <工作区输出PNG>` 仅渲染已可用字体样张。无需再次运行成员的安装脚本，不进行系统字体安装。

专项 QA 包括叙事匹配、历史证据、隐含时间线、展览身份、策展结构、视觉锚点、色彩符号、实际文字与事实；失败按成员表定向回退。叙事、证据及方向确认沿总 Gate 执行。

## 共同执行规则

本类别必须读取并执行上述中英文成员模块，不能只用旧类别摘要或自由省略专项规则。当前成员包是多方案策略与字体模块，没有固定样稿；强制的是成员模块及其设计规则，不自行编造一套固定版式。成员要求的方向候选、证据和确认接入总 Skill 现有 Gate；已有用户确认覆盖相应事项，不重复询问，也不另建竞争的主流程。

全部文化活动仍同时交付中文与英文两版完整海报，成员入口的默认语言只标识该子流程。总 `SKILL.md`、统一母本、4:5／2400×3000默认规格、双语事实映射、正式排版和交付检查保持。模块默认输出清单不是最终成品的替代。

资源从对应成员 `SKILL.md` 所在目录解析。字体已按哈希去重到共享资源目录，各包 `references/font-manifest.json` 的 `file` 和 `license_file` 已更新；以实际清单为准，不能从本类别文件目录寻找字体。字体名称写进提示词不算已加载，制作前逐份核对路径、哈希、字形覆盖和字号。

需要无字主视觉时调用总流程可用图像工具，再用可控工具排入真实文字。包内检查／样张脚本只验证资源和文字，不能当完整海报生成器，也不能宣称已通过完整海报端到端测试。所有样张和项目输出写入项目工作区，不写回成员资源目录。

成员示例、测试话术、预生成 JSON 和归类标签均不是新活动事实；继续执行 [类别模板与成员模块路由](../category-template-routing.md)、[双语规则](../bilingual-content.md) 及通用 QA。后续用户明确覆盖项集中记录在本类别入口或项目路由，不修改总入口。
