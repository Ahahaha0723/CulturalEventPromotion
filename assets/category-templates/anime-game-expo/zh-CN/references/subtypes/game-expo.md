# 游戏展：可参与内容与分区

潮流-044只有清单记录，实图与原路径缺失，因此不能做该案例字体识别；本模块为待图验证的策略。游戏展不等于电竞赛事、发布会或线上直播：核对观众主要行为是参观／试玩／交流还是观看比赛，必要时调整主类型。

需要展名、日期与开放时段、场馆、游戏／发行商资产、试玩／硬件／独立游戏／舞台展区、嘉宾、购票和入场条件。名单、展区、年龄级别、排队安排与平台兼容性只有来源明确才写，不创造游戏名称或参展商。

三条路线：真实试玩／硬件对象、与获准游戏资产相关的主视觉、文字和功能模块主导的展会系统。game-modular方案提供Rajdhani的有角度窄体与中文稳健黑体，但不是所有游戏都应采用科幻HUD。幻想、休闲、独立或复古题材分别选合适气质。

展区模块帮助查找，别把每个模块都放大到竞争。主海报与节目单／地图分工；地图需要真实场地资料，不生成假的导览。英文保留游戏、平台和展商官方写法；中文排版保护作品名、场馆与票种。需要补回044实图后，再判断其构图机制与原字体；目前任何候选字体都不称为044原字体。

生成及文字修订前读取[最佳适配参考的字体与排版锁定](../strict-reference-typography.md)，实际看图、对照样张并按角色锁定字形与布局。旧候选次序不能代替匹配判断；新增斜体、字族或布局变动须有本案／原图依据。
