# 严格依据最佳适配案例选择字体与模仿排版

## 本类别的默认执行标准
用户要求动漫展／游戏展的字体选择与文字排版严格、准确地模仿最优、最适合的参考。本规则在本类别生成、重排和字体修订时默认执行；如用户另给明确字体／版式／品牌要求，遵从其最新要求。原有三维主视觉分析继续适用，本文件细化文字层的约束。

必须先确定本案的最佳适配文字参考，再依据原图锁定角色字体与版式关系。不得先让调度器挑出一个覆盖字符的字体，再把它解释成风格匹配。不得用“字体随题材自由选择”“大概像参考”代替严格执行。

## 选择一个有依据的主排版参考
实际查看候选图，对照：活动形式（综合展／单IP体验／创作者公告）、传播任务、主视觉气质、真实标题与信息量、语言与字系、目标画布及观看尺寸。记录候选、适配证据、不能迁移的角色和最终选择；“最优”是本案有依据的比较判断，不是虚构客观排名或匹配百分比。
- 用户已明确指定排版参考时直接采用，在不同语言／画布的必要适配处说明原因，不换成AI自己的默认方案。
- 综合动漫展通常先比较022／014，单IP体验先比较052，创作者公告先比较053。游戏展按真实内容判断，不只因“游戏”就套052。
- 主视觉参考和文字参考可分别确定。文字系统原则上保持同一个主依据；借第二例某个文字角色时，写清来源、必要性和兼容关系，不随意混用每张图的亮点。

## 从原图建立字体与版式对应表
按主标题、活动形式／副标题、传播语、作者／品牌、日期数字、场地正文、CTA分别记录。原图没有的文字角色标记“参考无直接对应”，按已有角色的字形、重量、对齐和间距延伸；不得擅自添加新的风格家族。

|要素|必须观察和记录|实际执行|
|---|---|---|
|字体形态|衬线／无衬线、真实粗细、字面宽窄、笔画对比、内白、端点、倾斜、定制改造|字体已确证且可用则调用原字体；未确证则同类候选与原图对照，不能称为原字体|
|标题与副标题|可见字高、总宽、光学重量、主副比、分组、标点与完整名称|以真实文案试排；主副比例依据当前参考，不沿用类别通用字号比|
|空间关系|文字框、基线、对齐轴、上下距离、字距、行距、与主体／信息带交接|记录可见边界与关系，可用x/W、y/H、可见字高/H和文字宽/W；标明测量或估计及置信度|
|换行与阅读|行数、长短过渡、完整词组、日期／数字组合、阅读次序|遵从参考的节奏和分工，但不为像素相似删词、乱拆专名或改变活动事实|
|表现处理|全大写、斜体、颗粒、描边、磨损、遮挡与字标图形|仅迁移原图所支持的处理；官方字标使用原资产，原创题名另做可编辑构字|

不要把估计坐标称作精确测量。不同长宽比或文案长度时，严格保持角色、视觉重量与相邻关系，重新求位置；列出必要变动。不得拉伸字形、机械照搬全部坐标或为了固定行数缩小所有文字。

## 字体选择与锁定
1. 从参考中的具体文字区域比较字形；定制字标与实体字体分开。MANGA的几何字标不能直接等同于站酷庆科黄油体或Archivo Black。
2. 原字体身份未确认时，用同类最有依据的候选和实际文案制作并列样张；必要时同时显示原图同字样。按相近的可见字高比较粗细、宽度和内白，不以相同字号误判。记录主要差异和选择理由，不虚构匹配分数。
3. 锁定实际字体文件、字重／斜体、文件SHA、角色、字号／字距及换行。使用[显式字体核查工具](../scripts/reference_font_check.py)验证已选文件，不允许静默回退。没有符合目标的实体字形时，应继续寻找合适字体或采用可编辑原创构字，保留差距并交付review，不声称完成准确复刻。
4. 中文与英文分别核查。中文通常无法照搬拉丁字母的宽窄与内白：以同类笔画、重量、角色与版式关系完成语言适配，并明确适配范围。不能用横向挤压中文造窄体，也不能把英文拆字方法直接用于中文。

包内参考方案只是候选起点：reference-022、reference-052、reference-053。通用anime-character等也不是审美选择器。调用font_engine后仍需上述对照；reference_font_check核查锁定字体，不自动挑第二候选。

## 三案例文字规则
- **022／Manga Barcelona**：保留宽重几何标题／身份组合、粗实日期及紧凑清楚的功能文字关系；底部独立信息带是整体版式依据。中文原创题名优先比较稳健几何粗黑及受控构字；不能因“国漫”就默认圆润玩趣体。源图没有斜体衬线传播语，新增传播语应延续已有字形与角色，不能无依据加上英文书法感斜体。城市名三行只在真实名称和组合适配时迁移，不强行仿造。
- **052／Arcane World**：标题是窄长、粗重、白色无衬线，与角色肩部共同建立构图；正文中轴与日期顺序保留。优先比较Anton与Bebas Neue实际样张的字面重量，而不是默认Bebas即原字体。磨损仅限可辨的表现字。场馆衬线有原图依据，但不扩大为全部正文衬线。
- **053／NYCC Artist Alley**：作者名是高对比斜体衬线与宽字距；Artist Alley／Table F20是普通字宽的粗斜体无衬线；巨大NYCC是粗重无衬线。三者不可互换。新增Barlow BoldItalic是摊位文字可比较候选；Barlow Condensed BoldItalic宽度明显不同，不能仅因它是粗斜体就优先套用。右下小字独立，拥挤处在目标尺寸改善并记录变动。

## 排版锁定与验收
确定参考后，用真实中英文写入[文字参考锁定记录](../assets/typography-reference-lock-template.json)。先做标题—副标题—日期—正文的局部排版对照，再加入整张主视觉。保持参考的字体角色、粗细关系、光学主副比例、对齐轴、字距／行距、分组、日期落点与图文交接；偏离逐项有理由。

把原图局部、候选试排和成稿文字区并排查看，同时看完整成稿和实际投放缩略图。必须分别核对：字形匹配、层级比例、行组过渡、间距对齐、数字样式、图文关系、完整文案。记录每项证据及未解决差异。逐字、缺字、溢出检查通过，不能替代这些检查。

未经原图或任务依据，出现新增斜体／字族、明显窄化／圆润化、主副比例改变、日期位置随意移动或模板化排版，视为需要修订的文字问题，不能标为严格参考匹配完成。若为可读性／语义／比例调整，写出必要性及影响；只修受影响文字层，保留已认可主视觉。发布与最终审美仍待用户批准，但不为日常试排新增无依据的反复确认。

## 本次反馈的范围
国漫风起v01完成技术检查，并不意味着字体与参考已经严格对应。此次用户明确提高字体和排版标准；以后不得把v01的庆科黄油题名、英文斜体传播语、字号或信息带比例默认固化为本类模板。本次更新规则与候选，未重新制作或宣称v01已通过新的审美要求。
