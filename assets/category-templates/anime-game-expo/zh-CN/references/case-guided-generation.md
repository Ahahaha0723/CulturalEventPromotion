# 动漫展／游戏展：三案例主视觉、风格与文字排版借鉴

## 生成时必须落实的要求
生成本类别海报时，在确定概念、图像提示和文字版式之前读取本文件，并实际查看下面的参考原图。将用户本轮选定的三张优秀参考作为优先借鉴依据，依据真实活动选择适配的主参考及必要的支撑参考。用户提供新的参考或明确指定局部范围时，以最新选择为准。

每次分别说明并落实 **主视觉效果、视觉风格、文字排版** 三个维度：观察到的机制 → 本案适配理由 → 原创生产动作 → 成稿对照标准。不能只写“潮流、好看、参考风格”，不能只换配色或换一个字体。以具体任务内容替换参考中的角色、城市和事实；主体、文字和材料要形成同一命题。

|维度|看图与生产|成稿审核|
|---|---|---|
|主视觉效果|主体数量、视线／动作、裁切尺度、前中后景、焦点、方向、图文交接；依据本案角色、作品、城市或参与方式重建。|第一眼焦点是否明确？主体关系与活动内容是否成立？借鉴的空间机制是否可见？|
|视觉风格|线描或块面、色彩结构、颗粒、边缘、撕纸、笔触、情绪和对比；写入提示及图面规格。|材料、色彩与情绪是否统一？是否只堆叠动漫／赛博装饰而缺少内容依据？|
|文字排版|主副文字的字形、比例、字距、行组、阅读顺序，以及与人脸、轮廓和信息承载区的关系；用真实中英文试排。|图像与标题是否共同构成画面？活动名、日期、地点及必要行动信息是否可读？|

## 案例A：Manga Barcelona（潮流-022）
原图：[P700.jpg](../assets/reference-posters/P700.jpg)。本轮用户第一张图片与该图 SHA-256 一致。原库为高共识案例，仍不代表新成稿已经获得观众验证。

- **主视觉效果**：多个人物从左右与下缘进入画面，近似围到镜头前的群体合影。前景手势被放大、人物被边缘裁切，后景中央教堂塔楼建立纵深和城市辨识；顶部黑色蝙蝠形象补充趣味。视线与动作让观众感觉可以加入，传达聚会、社群与节庆感。吸引力来自互动关系，不能降为没有关系的角色贴图排列。
- **视觉风格**：变化的漫画轮廓线与轻薄、水彩感色块；天空蓝和白色构成明亮底色，建筑金黄增加温度，红色帽子与活动字标呼应。人物语言与城市环境结合。这里判断的是可见质感，不据此断言真实绘画工艺。
- **文字排版**：插画约占上部五分之四，底部独立白色信息带。红色几何定制 MANGA 字标、右侧三行城市名和左侧周年标记形成品牌组合；下方粗黑日期、较小场地与网址集中居中。阅读为群像 → 活动标识 → 日期 → 场地／网址。三行城市名是特定字标构成，不规定所有城市必须拆成三行。
- **本案转化**：适合综合漫展、动漫节或城市主题粉丝聚会。依据真实主题建立原创或获准群像，使用本案城市／环境线索；边缘裁切与人物远近形成参与感。信息带高度按实际文案与画布确定，不锁死五分之一。原创活动题名可借几何构字机制，既有官方标识继续使用真实资产。
- **检查**：人物是否存在视线／动作关系？城市与角色是否属于本案？底部是否有完整而自然的品牌—日期—场地层次？避免堆角色、随机地标或把正文压在面部上。

## 案例B：Arcane World（潮流-052）
原图：[P705.jpg](../assets/reference-posters/P705.jpg)。原库高共识；单 IP 主题体验证据，不是综合游戏展的直接效果验证。

- **主视觉效果**：正面蓝发角色特写几乎填满方形画面，头发、头部和肩部越过边缘。粉紫色眼睛在蓝黑环境中成为第一焦点；巨大的白色标题覆盖肩部与深色躯干，避开关键面部。角色负责情绪和 IP 辨识，标题负责活动身份，构成双锚点。
- **视觉风格**：角色有绘画笔触及块面光影，外围为蓝黑白撕纸拼贴、颗粒和磨损。细腻脸部与粗粝边缘构成材质对比；集中蓝黑白配色配合眼部少量粉紫，形成叛逆、紧张和街头气息。不是所有游戏展都应使用蓝色、撕纸或霓虹。
- **文字排版**：ARCANE WORLD 是一行超大白色、窄长、粗重的大写无衬线标题，紧凑地跨越大部分宽度；磨损与右端滴落让字面参与材质表达。下方场地、日期居中减小，最下方四组白色品牌标识横向分布。角色目光 → 大标题 → 场地／日期 → 品牌构成阅读路径。泰文、拉丁文字与 Logo 各有角色，不能把参考全文当作英文母本。
- **本案转化**：适合已确认单 IP、人物或作品主导的展览／体验。用获准人物图或本案原创主体确定眼神、裁切和标题承载区域；选择真实窄体字体，题名可作受控材质处理，小字保持清晰。中文依实际字形与题名长度重排，不横向压扁来仿造拉丁窄体。多 IP 综合展先考虑作品／展区关系，不自动选一个人物代表全部内容。
- **检查**：眼神与标题是否同时清楚且互不遮挡？纹理是否集中于可承受的区域？活动形式、场地和日期是否比品牌装饰更容易查找？不复制原 IP 角色、Logo 或泰国纪年为新活动事实。

## 案例C：NYCC · Artist Alley Table F20（潮流-053）
原图：[P96.jpg](../assets/reference-posters/P96.jpg)。本轮用户选定优秀参考；原库为较高分参考且有评分分歧，保持原档位。它是创作者摊位公告，不是全展官方主海报。

- **主视觉效果**：倾斜人物和中央相握的手建立叙事关系；巨大黄色圆形稳定构图。胶片状飘带、飞鸟、微型城市和星芒跨越不同尺度，下方腿部与鞋子加强纵深与动势。用一个具有作者识别度的浓缩故事吸引持续观看，关键是人物关系与空间组织。
- **视觉风格**：有笔触与颗粒的彩色叙事插画。紫色背景和黄色圆形形成冷暖对照，蓝色服装、橙红肤色、绿色树木及青色局部丰富层次。运动服饰、城市与幻想元素表达个人作品气质；这些具体元素不是创作者公告的固定清单。
- **文字排版**：顶部小字号宽字距展会全名，下一行较大的宽字距斜体衬线作者名，形成轻巧署名层。底部左侧 Artist Alley、粗斜体 Table F20、巨大粗体 NYCC 递进；右下角小字号右对齐日期与地址。文字直接与插画叠置，通过重量、尺度、倾斜和位置分工。右下小字较密，不能把其缩略图可读性当作范本。
- **本案转化**：适合同人／创作者展区及具体摊位公告。优先创作者自己的作品或获准素材，建立叙事与个人识别；让真实摊位编号成为行动定位信息，展会全名／作者署名各自清楚。中文允许采用相应阅读结构，英文署名与摊位可以分别调用真实斜体衬线与粗斜体无衬线。
- **检查**：创作者、宿主展会和摊位号能否分别辨认？观众是否知道去哪里？下部文字是否与插画衔接自然？日期／地址缩小后仍需可读。综合展主海报不能因借鉴此图就虚构摊位号或让展会缩写替代完整活动名。

## 三条路线的选择与组合
1. 综合漫展的聚会与城市叙事：优先A；信息很密时可结合既有014的功能模块。
2. 单 IP／角色主题体验：优先B；角色辨识与活动性质都需成立。
3. 创作者／同人摊位公告：优先C；作者作品及准确定位是核心。
4. 综合游戏展：根据真实游戏、玩法、试玩和展区主题选择可迁移机制。A的群体参与、B的单一焦点或C的原创叙事可局部借用；不能把三张图说成综合游戏展已验证的完整训练集。044缺图仍为 pending-case。

可以分配主视觉、材料和排版的不同参考，但要记录各自职责及统一命题。例如某原创插画展可学习C的叙事与A的独立信息带；不是把群像、角色特写与摊位巨字全部拼进同一张图。具体色彩、人物数量、比例、方向和字体按本案决定。

## 进入提示、排版与审核
- 图像工具支持参考图时，实际传入选定图片并注明构图／材质职责；不支持时记录未传图，改用具体观察描述。不只在提示里写“参考优秀案例”。正式小字继续可控排版。
- 生成提示写清本案内容锚点、主体关系与裁切、前后景／焦点、材料与配色、标题衔接区域和功能信息区。不要以案例日期、城市、IP 或摊位填补母本缺项。
- 字体先按[案例角色调度](font-routing.md)选真实文件并用实际文案试排。主副关系检查光学大小、边缘、间距与图像重心，不固定字号比；混用本身不扣分。英文字距不能用于掩盖任意拆词，中文不套用拉丁字母的拆分。
- 完整尺寸和实际投放缩略尺寸下，把成稿与主参考逐项对照三个维度。分别记录已实现、差距、保留部分及修订层；字体覆盖和导出通过不等于审美通过。
- 用户已接受的层保留。只反馈排版时先修文字；主视觉差距则回退主体／构图／材料，不随机换字体或提高分辨率。原有五项人工确认与终稿审核仍适用，已有明确决定直接沿用。
