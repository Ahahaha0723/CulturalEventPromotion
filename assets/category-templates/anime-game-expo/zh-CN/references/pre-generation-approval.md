# 生成前五项确认

首次主视觉生成前，将下表填成可读的简表展示给用户；不能只在后台把它标为通过。已有明确决定可直接沿用，标明哪次回复或哪份文件支持。用户只说“测试效果”时，不把五项全部视为已确认。

|项目|展示给用户的内容|可记录的状态|
|---|---|---|
|主方向|一句设计命题、观看入口、图文关系、拟采用小类策略|confirmed / pending|
|文化或身份元素|具体艺人／节目／剧种／作品／角色及依据；无此类元素也写明|confirmed / pending / not-applicable|
|素材授权|资产身份、提供者、允许的使用范围及未知项|confirmed / pending|
|画布比例|比例、像素或印刷规格、数量、语言、适用渠道|confirmed / pending|
|正式文字预留|题名、形式、阵容／节目／展区、日期地点和 CTA 所在区域；长文处理方式|confirmed / pending|

## 如何决定是否继续

- 内容与既有批准一致，直接继承，不再次询问。改变主方向、核心身份资产或输出范围时，只重确认发生变化的项。
- 用户已明确授权快速试稿、选定方向或指定 AI 自行判断时，记录授权的具体范围并继续；这种授权允许探索，不证明未知版权、官方译名或历史身份已确认。
- 未有方向授权且方向会实质影响生成时，向用户给出简短可选方向并等待；可同时完成资料盘点、字体样张、事实映射等不依赖方向的工作。
- 探索许可与正式发布许可分别记录。未知关键事实或核心资产权限不通过终稿；探索图不能伪装成真实演出纪实、官方作品或官方IP资产。
