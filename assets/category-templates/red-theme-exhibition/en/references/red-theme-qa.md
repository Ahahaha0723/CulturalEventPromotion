# 红色主题专属 QA 与定向回退

| QA 项 | 通过要求 | 失败回退 |
|---|---|---|
| Narrative Match | 叙事与具体策展内容匹配，非默认时间轴 | Narrative Strategy Selection |
| Anti-Template | 不靠红金/飘带/卷轴/空泛符号拼贴做默认答案 | Narrative / Poster Visual |
| Evidence | 人物/年份/档案/影像/文物可追溯、有许可或限制记录 | Historical Evidence & Provenance |
| Implicit Timeline | 非时间线方案未被年份阅读顺序主导 | Narrative Strategy Selection |
| Exhibition Identity | 除标题外仍能识别是一场展览，有展陈内容及参观信息 | Exhibition Identity + Curatorial Structure |
| Curatorial Structure | 单元有统一视觉与信息规范，不是随意拼块 | Curatorial Structure |
| Poster vs Directory | 有清晰视觉锚点，远距识别，不是展板/目录 | Poster Visual Strategy |
| Color & Symbols | 视觉元素有依据且克制，避免滥用宏大符号 | Concept / Cultural Evidence |
| Information | 标题、主叙事、日期、地点、方式可读完整，不编造 | Brief Fact Master / Information Hierarchy |
| Typography | 真实字体路径、字形覆盖、书法字体短标题、中文英文独立排版 | Typography / Layout QA |
| Gate | 用户已明确确认类别与设计方向，未确认阻断正式生成 | 总Skill Gate |

必须记录每项 Pass/Fail/Pending；Fail 定向回退，Pending 不能虚报 Pass。
