# 本地部署（先看这个）


> 当前合并版：九份字体已随总包提供，马善政／志莽行书原成员哈希匹配。以 `references/font-manifest.json` 的共享路径为准；本机无需再次执行安装脚本。提示计划与排版文件按 `references/red-theme-typography.md` 的绑定步骤执行。下文安装步骤仅保留原成员包历史说明。

这个 ZIP 是**不含字体二进制文件的类别 Skill 模块**。作者已用上传的字体包检查了字体可读性、基础中英文字形、文件哈希；字体资源在你自己的电脑上安装进模块后，才可在排版工具里真正调用。

## 准备
把以下原始文件放入一个文件夹：
- `09_SourceHanSerifSC.zip`
- `09_SourceHanSansSC.zip`
- `Ma_Shan_Zheng,Nunito,Zhi_Mang_Xing.zip`
- `LXGWWenKai-Regular.ttf`

`Nunito,Zhi_Mang_Xing.zip` 与以上合包内容重复，无需放入。

## 安装和验证
在此模块目录打开终端：
```
python -m pip install fonttools pillow
python scripts/install_local_fonts.py "D:\你的字体文件夹"
python scripts/check_fonts.py
python scripts/render_font_sample.py
```
执行后生成字体样张 `font-render-sample.png`。只有通过字体 hash、字形及样张检查，才能认为本地字体安装成功；这并不代表总 Skill 的图像生成链路已验证。
