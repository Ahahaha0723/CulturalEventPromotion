# 红色文化／党史展览类型策略（red-theme-exhibition）

## 适用范围与集成边界
- 只在总 Skill 已识别并经用户确认主类型为 `red-theme-exhibition` / 红色文化、党史主题展览时加载。
- 本模块专管此类别的叙事、历史真实性、策展结构、视觉策略、字体、QA；不得覆盖总 Skill 的 Brief 事实母本、总分类器、通用 Gate 及导出流程。
- 生成前确认是必要条件；若总 Skill 尚无强制 Gate，须在合并阶段补齐，并让调用程序阻断未确认的正式生成。

## 1. Narrative Strategy Selection（必需）
先根据用户的展览内容选一种主叙事（可选一种辅助叙事）：时间线、历史事件、真实人物、档案文献、文物证据、历史命题/策展单元、精神主题象征。
- 时间线仅在用户明确需要时间历程，或 Brief 以历史演进为核心且经用户确认时选用；不得把“红色文化”直接路由为时间轴。
- 必须给出所选叙事、对应展览内容、素材依据及风险，不得凭配色决定叙事。

## 2. Anti-Template Rule（必需）
以下不得成为默认结构：满版红底+金字、飘带/道路/卷轴、固定 1921→2026 演进、历史照片拼贴+时间轴、无主题依据的光芒/山河/长城符号。
- “禁默认”不等于一律禁用：有可靠内容依据、传播适配且用户确认时允许使用。
- 同任务重试时，至少提出两种叙事或阅读逻辑实质不同的方案；不能仅移动装饰或改变字色冒充新方案。

## 3. Historical Evidence & Provenance（硬约束）
在主视觉定稿前制作 evidence ledger：元素/事件、身份、来源 URL 或用户文档、使用许可/限制、对应展览内容、核实状态（verified/pending/conflict）。
- 人物：真实身份、年代、相关事件；照片：拍摄/发表时间、事件语境、出处、版权；档案：真实名称、年份、馆藏出处；文物：名称、年代、机构；年份：必须对应具体历史事件/展陈单元。
- 权威素材优先：用户附带可靠资料、博物馆/档案馆/党史机构/政府文化部门、正规出版物和学术研究。
- 网络检索只能生成候选资料，来源未经核实或用户未确认，不得直接当作事实图像。不能使用假印章、假编号、伪造文件文字、合成历史照片冒充原始史料。
- 如果缺乏资料，允许抽象几何与具有说明的象征表达，但必须标为概念设计；不能在画面上让用户误以为是原件。

## 4. Implicit Timeline Check（必需）
非时间线策略中，年份仅作说明，不得成为视觉阅读主线。检测：节点按年份串联、连续箭头/编号引导年代、网格仍按早晚顺序形成演进权重。如发生则退回叙事策略重做。

## 5. Exhibition Identity Control（必需）
必须呈现展览性质、主要展示内容（文献/影像/人物故事/展品/互动至少有相关项）以及日期、开放时间、地点、参与方式；有则呈现主办方。不得由模型编造机构、地点、展品、预约方式。
- 检验法：遮盖活动标题后，依据其他信息仍应能识别它是一场展览，而非单纯口号海报。

## 6. Curatorial Structure System（必需）
策展单元须有一致的字号、字体角色、说明格式和对齐规则；不可把功能信息和表现性标题用同一书法字体。
若采用 2×3/3×2 等网格，网格需为内容组织服务，不得退化成文字目录页。

## 7. Poster vs. Directory Balance（必需）
保持远距离可识别的主视觉锚点，可为可验证的文物/档案细节、具有依据的人物、强化的策展命题或材料叙事。信息充分不意味着海报成立；若视觉只剩目录回到主视觉策略。

## 8. Color & Symbol Restraint（必需）
允许象牙白、米色、炭黑、氧化暗红、砖红、少量暗金等。红色是可选识别色而非满版背景默认值。无依据的旗帜/星芒/长城等不应堆叠；政治和历史词语优先保证准确识读。

## 9. 工作流与确认
Brief事实核查 → 总Skill分类确认 → Narrative Strategy Selection → Evidence Ledger → Implicit Timeline Check → Exhibition Identity + Curatorial Structure → Poster Visual + Typography Strategy → **Gate：人工确认叙事、证据、时间线使用、主视觉、版式、真实性风险** → 主视觉生成 → 包内真实字体排版 → 分类QA → 有原因的定向回退。
- 无明确确认不得正式生成；请勿把“生成一张”默认为跳过 Gate。
- 默认不得在图片模型生成中假设字体已经真正加载；推荐图像主视觉与可控文字排版分离。
