# Toy / Brand Pop-up Fixed Template Typography (English)

## Default font system for this round
### English version default
- **title / title mark**: Nunito Bold by default
- **metadata / body / bottom panel**: Nunito Regular / Bold

### Chinese support when needed in bilingual layouts
- Chinese title: ChillRoundF (optional)
- Chinese metadata / body: Source Han Sans SC

## Why this system is fixed
- Nunito is friendly, readable, and stable for English information-heavy poster layouts
- Source Han Sans SC remains reliable for Chinese meta information
- ChillRoundF can be used selectively when a rounded playful title treatment is needed

## Functional role split
### 1. Top-left info block
- Font: Nunito Bold / Regular
- Date: Bold
- Venue / address: Regular or smaller Bold
- Avoid extreme stretching or overly thin condensed looks

### 2. Upper-middle title mark area
- Default: Nunito Bold with custom lettering treatment
- Prefer a unified wordmark-like treatment rather than ordinary text lines
- Keep the number of title lines low

### 3. Bottom information panel
- Main line: Nunito Bold
- Feature line: Nunito Bold / Regular
- Support sentence: Nunito Regular
- If information becomes dense, remove the icons first rather than shrinking text too much

## Not recommended
- Too many display fonts on one poster
- Decorative fonts for dense informational copy
- Overly large title lettering that blocks the character face or key identity features
