# Character-Centered Fixed Template V2

## Template purpose
To lock the toy / brand pop-up poster into a reusable structure instead of reinventing the layout every time.

## Fixed skeleton
- top-left: date / time / venue
- upper-middle: title badge / lettering mark
- middle-back: collage wall
- mid-lower: hero character
- bottom-center: information panel

## Elements that should stay fixed
- 3:4 vertical canvas
- five-zone structure
- hero character in the mid-lower focal area
- top-left reserved for meta information
- bottom-center reserved for event information panel

## Elements that may change
- brand / IP
- hero character
- palette (green / yellow / blue)
- collage contents
- title lettering style
- whether icons are used in the bottom panel

## Suggested copy structure (EN)
- top-left:
  - date
  - open daily
  - venue
- upper-middle:
  - brand / event title
- bottom-center:
  - theme title
  - 3–4 feature phrases
  - one support sentence
