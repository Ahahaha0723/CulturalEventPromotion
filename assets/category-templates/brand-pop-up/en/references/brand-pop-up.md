# Toy / Brand Pop-up Category Strategy (Fixed Template Final Test Edition)

## 1. Scope
This category covers:
- designer toy / collectible IP pop-ups
- brand-themed pop-ups
- temporary concept stores
- character-centered themed activations
- events driven by collecting, check-ins, installations, or interaction

Default classification:
`primary_type = festival`, `sub_type = brand-pop-up`

## 2. Fixed master layout for this round
Default layout:
**Character-Centered Fixed Template V2**

Canvas: **1080 × 1440 px, vertical 3:4**

### Five fixed zones
#### Zone A | Top-left info block
Contents: year, date, opening hours, venue

Rules:
- date and opening hours are the first hierarchy
- venue is the second hierarchy
- the date should be slightly larger than the address, but not dramatically larger
- left aligned, clean, refined, readable
- avoid overly bold or overly condensed / stretched forms

#### Zone B | Background collage wall
Contents: 3–5 rectangular visual blocks that build the world of the brand / IP

Rules:
- works as environmental context and atmosphere
- must remain background support, not the main focal point
- all blocks should share one color treatment
- recommended materials: scene, product, installation, close-up detail, brand visual motif

#### Zone C | Upper-middle title badge area
Contents: event title / lettering / brand wordmark zone

Rules:
- this is the main visual headline area
- if a real brand logo is available, it may be integrated without altering the brand identity
- otherwise build a custom typographic title mark using the selected display font
- prefer a cohesive badge / lettering treatment over plain text lines

#### Zone D | Mid-lower hero zone
Contents: one main character / one key visual subject

Rules:
- the hero should occupy around 40%–50% of the overall visual weight
- place it in the mid-lower area as the dominant focal point
- face and identity-defining features must remain clear
- the hero must not become too small or secondary

#### Zone E | Bottom-center information panel
Contents: theme subtitle, key highlights, event details

Rules:
- default panel style is a **dark semi-transparent rounded rectangle**, centered
- when content is short, a small number of icons may be kept
- when content is dense, **remove the icons by default** and use centered text
- do not repeat the time / venue already shown in the top-left info block
- use this panel only for theme description, highlights, experiences, and participation / purchase notes

## 3. Chinese vs English layout differences
### Chinese
- top-left block can run 2–4 lines
- title can be more expressive
- bottom panel may use “main title + one highlight line + one support line”
- compact centered text works well

### English
- reduce awkward line breaks in the top-left area; keep word groups intact
- the title mark may be wider, but must not crush the date block
- the bottom panel should preferably follow a 2–3 level structure:
  - Level 1: event theme title
  - Level 2: short feature phrases
  - Level 3: one support sentence
- avoid excessive small copy in English

## 4. Color schemes
Allowed master palettes:
- `green`: retro-tech / space collectible / urban pop-up
- `yellow`: playful energy / cute vibrant / high-key toy mood
- `blue`: fresh futuristic / cosmic roaming / dreamy tone

### Hard color rule
1. The hero, background, and title badge must share one coherent palette logic.
2. **The hero color treatment must match the dominant background palette.** Avoid a situation where the background is strongly green while the hero remains a conflicting bright warm palette with no harmonization.
3. If the original hero palette conflicts, fix it through one or more of the following:
   - choose a more suitable outfit / version of the character
   - unify environmental lighting
   - echo the hero’s accent colors in the layout
   - reduce the area of conflicting colors
4. It is not acceptable to recolor only the background while leaving the hero visually disconnected.

## 5. Real brands / IP use
- For testing, prefer real recognizable brands / IP such as POP MART, MOLLY, LABUBU, etc.
- If the work is conceptual and unofficial, add a notice such as: `CONCEPT EVENT / UNOFFICIAL RELEASE`.
- Do not fabricate “official collaboration”, “inventory limits”, or “gift rules”.

## 6. Recommended information hierarchy
1. event name / main title
2. date + opening hours
3. venue
4. highlight phrases (for example: limited collectibles / photo experience / interactive activities)
5. one short support sentence

## 7. Current testing goal
This round is not about infinite variation. It is about checking:
- template stability
- Chinese layout stability
- English layout stability
- improved palette harmony
- better control of the bottom information panel
