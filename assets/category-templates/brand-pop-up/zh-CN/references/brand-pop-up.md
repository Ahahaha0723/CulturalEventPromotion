# 潮玩 / 品牌快闪类别策略（固定模板最终测试版）

## 1. 适用范围
本类别用于：
- 潮玩 IP 快闪
- 品牌主题快闪
- 限时体验店
- 角色中心型主题活动
- 收藏 / 打卡 / 装置 / 互动导向活动

默认 `primary_type = festival`，`sub_type = brand-pop-up`。

## 2. 本轮固定下来的主版式
默认主版式为：
**Character-Centered Fixed Template V2（角色中心固定模板 V2）**

画布：**1080 × 1440 px，竖版 3:4**

### 五个固定区域
#### 区域 A｜左上信息区
放置：年份、日期、营业时间、地点

规则：
- 日期与营业时间为第一层级
- 地点为第二层级
- 日期字号比地址略大，但差距不能过大
- 整体左对齐，保持精致、简洁、可读
- 不能过粗、不能过于拉长

#### 区域 B｜后方拼贴墙
放置：3–5 张矩形背景素材，形成品牌/IP世界观拼贴

规则：
- 作为环境信息与气氛来源
- 只能做背景，不抢主角色
- 保持统一色调处理
- 素材建议包括：场景、商品、装置、近景细节、品牌视觉元素

#### 区域 C｜上方中央活动字标区
放置：活动主标题 / 字标 / 品牌字样

规则：
- 这是主视觉中的“标题徽章”区域
- 若有真实品牌 Logo，可结合使用，但不能破坏品牌原貌
- 若没有可嵌入的标准 Logo，则用指定展示字体重构标题
- 优先做成整体性强的字标，不用普通散排标题

#### 区域 D｜中下主角色区
放置：单一主角色 / 单一主视觉主体

规则：
- 主角色占整体画面约 40%–50%
- 位于中下区域，成为视觉中心
- 角色面部、标志性特征必须清晰
- 不允许角色缩得太小，或退化成配角

#### 区域 E｜底部中央信息板
放置：活动主题副标题、活动亮点、活动细节

规则：
- 默认使用**深色半透明圆角矩形**，居中放置
- 当信息不多时，可保留少量 icon
- 当信息偏多时，**默认删去 icon**，改为居中文本排版
- 信息板不得重复左上角已展示的时间地点
- 信息板只放：主题说明、活动亮点、体验内容、购买 / 参与信息

## 3. 中英文版式差异
### 中文版
- 左上信息块允许两到四行
- 标题可更有造型感
- 底部信息板建议“主标题 + 一行亮点 + 一行补充说明”
- 中文更适合紧凑、居中的信息表达

### 英文版
- 左上信息块要减少断行，优先保持词组完整
- 标题字标可更宽，但不要挤压到日期区
- 底部信息板建议采用两级结构：
  - Level 1：主题标题
  - Level 2：活动亮点短语
  - Level 3：一句补充说明
- 英文不宜堆太多小字

## 4. 色彩方案（固定系列）
允许三套主色方案：
- `green`：复古科技 / 太空收藏 / 都市快闪
- `yellow`：活力可爱 / 童趣能量 / 高明度潮玩
- `blue`：清爽未来 / 宇宙漫游 / 梦幻感

### 色彩执行硬规则
1. 角色、背景、标题徽章必须共享同一套主色逻辑。
2. **主角色色调必须与背景主色匹配**；不得出现“背景整体偏绿，但角色仍是高饱和黄橙且未调和”的割裂效果。
3. 若原始角色配色冲突，应优先通过以下方法修正：
   - 选择更匹配主色的角色版本 / 服装版本
   - 统一环境光颜色
   - 用局部辅色呼应角色原色
   - 降低冲突色面积
4. 不允许只给背景上色、角色完全不做协调。

## 5. 真实品牌/IP的使用要求
- 用户要求测试时，优先使用现实中可识别的品牌/IP名称，例如 POP MART、MOLLY、LABUBU 等。
- 如为非官方概念稿，必须在底部或角落标注：`概念活动 / 非官方发布`。
- 不能凭空写“官方联名”“限量库存”“赠品规则”。

## 6. 推荐的信息优先级
1. 活动名 / 主标题
2. 日期 + 营业时间
3. 地点
4. 活动亮点（如：限定收藏 / 装置打卡 / 互动体验 / 主题摄影）
5. 补充说明（一句）

## 7. 当前测试目标
本轮测试不是追求无限变化，而是验证：
- 模板是否稳定
- 中文版是否稳定
- 英文版是否稳定
- 色彩匹配是否改善
- 底部信息板是否可控
