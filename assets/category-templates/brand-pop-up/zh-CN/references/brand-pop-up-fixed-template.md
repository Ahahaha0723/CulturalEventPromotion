# Character-Centered Fixed Template V2 说明

## 模板目的
把“潮玩 / 品牌快闪”海报固定为一套可复用的结构，而不是每次重新发明版面。

## 固定骨架
- 左上：日期 / 时间 / 地点
- 上中：活动字标 / 标题徽章
- 中后：拼贴墙
- 中下：主角色
- 下中：信息板

## 不可轻易改动的内容
- 3:4 画幅
- 五区结构
- 主角色位于中下视觉中心
- 左上为信息区
- 下中为信息板

## 可变化的内容
- 品牌/IP
- 角色形象
- 色彩方案（green / yellow / blue）
- 拼贴墙素材内容
- 标题字标风格
- 底部信息板是否保留 icon

## 推荐测试文案结构（中文）
- 左上：
  - 日期
  - 营业时间
  - 地点
- 上中：
  - 品牌名 / 活动名
- 下中：
  - 活动主题句
  - 三到四个亮点词
  - 一句补充说明

## 推荐测试文案结构（英文）
- Top-left:
  - date
  - open daily
  - venue
- Upper-middle:
  - brand / event title
- Bottom-center:
  - event theme title
  - 3–4 feature phrases
  - one supporting sentence
