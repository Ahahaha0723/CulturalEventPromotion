# 潮玩 / 品牌快闪固定模板 QA（中文）

## Critical
- [ ] 是否确实属于潮玩 / 品牌快闪类别
- [ ] 是否使用固定模板，而非随意换版式
- [ ] 是否使用真实品牌 / IP 名称，或明确标注为概念活动
- [ ] 是否避免虚构联名、赠品、库存、官方关系
- [ ] 左上是否为日期 / 时间 / 地点，而不是其它信息
- [ ] 主角色是否与背景主色调匹配，未出现严重色彩冲突

## Major
- [ ] 五区结构是否稳定
- [ ] 上方中央标题区是否成立
- [ ] 主角色是否位于中下中心，且足够大
- [ ] 底部信息板是否居中、平整、清晰
- [ ] 底部信息板是否避免重复左上时间地点
- [ ] 中文版与英文版是否分别优化布局，而不是机械直译

## Minor
- [ ] 图标数量是否合理
- [ ] 标题与拼贴墙是否有足够层次差
- [ ] 小字是否清楚
- [ ] 角落注释是否完整

## 常见失败与回退
| 失败现象 | 回退位置 |
|---|---|
| 版式又跑飞了 | 回退到模板选择 |
| 角色与背景颜色不搭 | 回退到色彩方案 / 主视觉选择 |
| 左上信息太粗太大 | 回退到信息层级与字体设置 |
| 下方信息板太乱 | 回退到信息板规则 |
| 标题像普通文字而不是字标 | 回退到标题区设计 |
| 英文版拥挤断词 | 回退到英文排版 |
