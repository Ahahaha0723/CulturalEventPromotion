# 构图与表达路线：潮流演出

先根据节目内容与传播任务选择一个主导机制，不把三个小类做成同一套“霓虹酷黑”。下表是可比较方案；每次只展开与母本有关的两至三条。

|条件／任务|画面组织|字体与中文信息|英文重排|适用方案|
|---|---|---|---|---|
|Livehouse：气氛／概念优先|一个可说明的意象或真实现场；题名与意象互为焦点；日期城市独立|重黑、宋体或定制题名按音乐内容比较；票务信息常规清晰|短题名可集中；长题名按语义行组，不把全句压成窄条|livehouse-atmospheric|
|音乐节：阵容优先|干净名单区与场景区分工；分日／舞台另设模块|艺人名遵循给定顺序和等级，比较厚宋与粗黑；官方英文艺名保持原写法|按艺人完整姓名组行，等级一致但字号可随实际长度微调|festival-lineup|
|音乐节：场域优先|地形、城市或真实舞台空间形成场域；阵容与时间留独立区域|场景不能压倒城市、日期与必要阵容；有密度时派生日程版|保留全日期范围与时区意义；不猜 headliner 或 billed order|festival-lineup|
|演唱会／巡演：人物与品牌优先|确认的人物肖像、官方字标、巡演主题；城市场次模块可复用|新题名与官方字标分开管理；长城市名用常规宽度或真实窄体|艺术家、巡演名、城市层级分明；窄体适合短日期／地点而非所有正文|concert-portrait|

色彩先来自节目、艺人规范、场域或概念。可以黑白颗粒、单一高饱和色、照片自然色或有限双色；不用统一“潮流色卡”。纹理只作用于允许装饰的画面层，文字保持可读。运动感可以通过方向、切割、节奏、光线或人群空间表达；不需要每案加入伪舞台灯和烟雾。

标题、副标题、名单、日期城市、票务分别设置文本框与角色。先确定题名与主画面怎样形成一个整体，再调整字级；避免标题孤悬、名单挤成墙、日期被纹理吞没。4:5、9:16、横版、方形各自重新安排焦点，不能把竖版截掉底部信息当作适配。

每案在提示计划中填写：演出身份 → 真实主题锚点 → 主视觉焦点 → 图文关系 → 颜色／材料逻辑 → 五项待确认 → 禁止虚构事项。主视觉生成时不带正式文案；排版时读取母本和实际字体。保留被用户认可的主视觉，只修指定文字问题。
