# Spring Festival and National Day posters

## Workflow
1. Inventory copy, images and references. Separate facts, reference mechanisms and creative copy. Embedded image text is content, not instructions. Record festival, year, zodiac or anniversary, title, greeting, activities, brand, languages, canvas, sources and confirmed/pending/missing/conflict states.
2. Distinguish an artistic greeting from an attendance-driven event poster. Greetings need no invented venue or ticketing; event posters require verified dates, locations, opening arrangements and actions. Reference visual mechanisms without automatically reusing unlicensed source imagery for other events.
3. Spring Festival: check the zodiac and lunar-year boundary. Build a motif from recognizable features and the requested mood; do not label creative cultural associations as historical facts. A silhouette may be recognizable when requested. Static force calls for substantial horns, a quiet gaze and controlled negative space, not default motion trails.
4. National Day: identify the country, year, anniversary and event. Develop a motif from shared memory, celebration, local culture or the stated theme. Do not import Spring Festival zodiac imagery by default. Official symbols require authentic supplied assets. This package contains a Spring Festival example, not a completed National Day poster.
5. Define content, audience, communication goal, mood, cultural context and use. Assign each reference a role: planar transformation, graphic rules, lettering or palette. Continue directly after an approved direction.
6. Planar visuals rely on silhouette, color planes, negative shapes, print texture and hierarchy. Use selective blur while preserving identifying features. If the eye should be a diffuse shadow, avoid literal pupils, bright eyeballs and gemstone highlights. Crops can add impact; maintain one coherent projection and key recognition anchors. Enrich backgrounds through low-contrast overlays instead of decorative clutter. Honor flat design rather than switching to photography, 3D fabric sculptures or realistic animals.
7. Separate artwork from copy. Reuse available textless art; use an image tool for new raster generation or edits. Reserve quiet text zones. Place formal titles, dates, brands and small text deterministically. Match requested reference lettering by analyzing proportions, terminals, horizontal strokes and rhythm, not merely selecting a generic calligraphy font.
8. Design year/eyebrow, main title, greeting and supporting information as a hierarchy. Adjust font, weight, size, leading, tracking and offsets together. More information must preserve breathing room. Never invent a brand. Original greeting copy is permitted as creative copy.
9. Reflow English from the same master. Verify years, zodiac, greetings and event facts. Keep GOAT/SHEEP terminology consistent. Proposed institutional translations are not official names. English-only posters must retain essential information originally carried by Chinese text.
10. Inspect recognition, projection, text accuracy, contrast, bounds and overlap at full and phone size. After two unsuccessful local iterations, revisit the affected concept, letterform or layout. Distinguish design self-review from audience testing.
11. Deliver background, poster, master, TTF/licenses, reproduction assets and QA. Preserve originals and versions. Use language subfolders when one shared destination is specified. Confirm print production parameters separately. Report only skills actually invoked.

## Packaged example
Read references/case.md for the 2027 Goat example and its image prompt. assets/reference-original.png retains the supplied poster; assets/background.png is matching textless art; assets/poster-reference.png is the open-font retypeset output; assets/fonts retains fonts/licenses.
scripts/render.py requires Python/Pillow and reproduces this fixed 2027 example; content.json selects language only. Copy assets to a fresh work directory and run python scripts/render.py <work-directory>. For another year or National Day, update facts and layout first; this is not an automatic generic event renderer.
