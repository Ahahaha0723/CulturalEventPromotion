# 使用说明

这是2026-10-12的专题补充交付版。SKILL.md为入口；references为策略与审核说明；assets/fonts包含可直接加载的字体实体、许可、角色索引及调度记录；assets/font-proofs为原图局部与候选字体对照；scripts/font_engine.py可离线检查字符覆盖并输出实体路径。

本中文版说明支持中文和英文海报，并分别提供两种语言策略。对应英文压缩包的技能名称相同，只选择一个说明语言版本。同类专题和完整集成版建议选一种作为主入口，避免触发选择重复。

先按具体活动读取小类、语言和构图路线，再审阅真实文案的字体样张，记录主方向、文化／身份元素、素材权限、画布比例和文字预留五项决定。已明确的决定直接沿用；未确认的事项如实标注。新规则为trial，技术校验不能替代人工审美审核。

字体均为来源可追踪的开源替代候选；案例原字体精确确认数为0。官方字标、改造字与海报图片不可因为字体许可而任意公开复制。请查看case-evidence与font-identification中的缺项及原评分档位。

使用字体脚本需要Python3，无额外包；YAML内容校验需要PyYAML，使用JSON可以避免此依赖。生成主视觉时使用当前可用的图像生成能力；本包不包含模型权重，也不保证特定工具自动产生好审美。
